# PPL Programming Practice

## Giới thiệu

Repo này chứa bài tập thực hành cho môn Principles of Programming Languages (PPL), bao gồm:

- Functional Programming (FP): 13 câu hỏi về higher-order functions, recursion, list comprehension
- Object-Oriented Programming (OOP): 3 câu hỏi về class hierarchy, methods, và Visitor Pattern

Mỗi topic có:

- `practice_questions.md`: Đề bài chi tiết
- `practice_test.py`: File để code và test
- `solutions.py`: Đáp án tham khảo

## Cách sử dụng

1. Đọc đề trong `practice_questions.md`
2. Code trong `practice_test.py`
3. Chạy test: `python FP/practice_test.py` hoặc `python OOP/practice_test.py`
4. Tham khảo `solutions.py` nếu cần
